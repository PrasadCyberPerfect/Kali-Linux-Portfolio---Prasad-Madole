# Kali Linux Portfolio

A premium interactive portfolio designed to look and feel like a Kali Linux desktop environment!

## ✨ Features
- 🖥️ Kali Linux inspired desktop UI
- 🎯 Draggable floating windows
- 🎮 Retro Snake game
- 📱 Fully responsive design
- 📄 Clean modular architecture

## 📁 Project Structure
```
kali-linux-portfolio/
├── index.html
├── css/
│   ├── main.css
│   ├── desktop.css
│   ├── windows.css
│   ├── animations.css
│   └── responsive.css
├── js/
│   ├── app.js
│   ├── drag.js
│   ├── navigation.js
│   ├── window-manager.js
│   ├── projects.js
│   └── snake-game.js
├── assets/
│   ├── icons/
│   ├── images/
│   └── certificates/
└── data/
    ├── projects.json
    └── certifications.json
```

## 🛠️ Installation
1. Download or clone the project
2. Open `index.html` in any modern browser
3. Enjoy your Kali Linux portfolio!

## 🎨 Customization
- Update `data/projects.json` to add your projects
- Update `data/certifications.json` to add your certifications
- Customize colors in `css/main.css` variables
