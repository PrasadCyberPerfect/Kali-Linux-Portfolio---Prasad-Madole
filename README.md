Kali Linux Portfolio
A premium interactive portfolio designed to look and feel like a Kali Linux desktop environment!

✨ Features
🖥️ Kali Linux inspired desktop UI
🎯 Draggable floating windows
🎮 Retro Snake game
📱 Fully responsive design
📄 Clean modular architecture

🛠️ Installation
Download or clone the project
Open index.html in any modern browser
Enjoy your Kali Linux portfolio!
🎨 Customization
Update data/projects.json to add your projects
Update data/certifications.json to add your certifications
Customize colors in css/main.css variables
